# برنامه بازطراحی اساسی رابط کاربری هم‌ره

> **جایگاه این سند:** این فایل فقط برنامه تخصصی لایه UI/UX است و زیرمجموعه [منشور مادر پروژه](./PROJECT-CHARTER.md) محسوب می‌شود. ترتیب کلی توسعه از M00 Foundation آغاز می‌شود؛ اجرای این برنامه و بازطراحی صفحات واقعی پس از تثبیت قراردادهای داده، مجوز و منطق هر حوزه انجام می‌شود. UI Reference ابزار ارزیابی طراحی است، نه مانع توسعه زیرساخت و منطق پایه.

**وضعیت:** در حال اجرا  
**شاخه مبنا:** `feature/filament5-upgrade`  
**هدف:** جایگزینی تدریجی رابط پراکنده و CSSهای موردی با یک نظام طراحی مرکزی، واکنش‌گرا و فارسی.

## تصمیم مالک

تمام صفحات موجود باید بازنگری شوند. هدف، وصله‌زدن ظاهر فعلی نیست؛ باید ساختار اطلاعات، سلسله‌مراتب بصری، چیدمان، فرم‌ها، جداول، ناوبری و تجربه موبایل از نو طراحی شود. زیبایی و انسجام بصری اولویت بالای پذیرش است.

## اصول غیرقابل نقض

- منطق کسب‌وکار، Policyها، مجوزها، رویدادها، اعتبارسنجی و محدوده‌بندی `company_id` در بازطراحی UI تغییر ناخواسته نمی‌کنند.
- هیچ داده عملیاتی، Migration، Action یا مسیر کاری صرفاً برای ساده‌کردن ظاهر حذف نمی‌شود.
- CSS اختصاصی Resource و Page مقصد نهایی نیست؛ هر استثنا باید مستند، محدود و موقت یا دارای دلیل روشن باشد.
- ابتدا قابلیت‌های بومی Filament 5 و الگوهای مشترک؛ سپس Blade/Livewire اختصاصی در صورت نیاز واقعی.
- دسکتاپ، تبلت و موبایل سه حالت طراحی‌شده‌اند؛ موبایل نسخه کوچک‌شده دسکتاپ نیست.
- حالت روشن و تاریک باید هر دو پشتیبانی شوند.
- تمام کنترل‌های لمسی، focus، keyboard، reduced motion و safe-area باید بررسی شوند.
- هیچ صفحه‌ای تا زمان بررسی رفتار داده، مجوز و تست‌های مرتبط صرفاً با معیار ظاهری پذیرفته نمی‌شود.

## ممیزی اولیه مخزن

در زمان شروع بازطراحی، شاخه رسمی دارای این ساختار بود:

- ۱۰۴ فایل PHP در `app/Filament`
- ۸ قالب Blade در `resources/views/filament`
- ۱۱ فایل CSS در محدوده پروژه
- فایل‌های CSS منتشرشده Filament نیز در مخزن حضور دارند؛ این خروجی‌های build منبع طراحی نیستند و نباید دستی ویرایش شوند.

### منابع اصلی استایل که باید مهاجرت کنند

| مسیر | وضعیت/ریسک | مقصد |
|---|---|---|
| `resources/css/filament/admin/hamareh-ds.css` | توکن‌ها و قواعد پایه، همراه با فونت و قواعد قدیمی | توکن و اجزای مشترک نسخه نهایی |
| `resources/css/filament/admin/hamareh-ds-polish.css` | لایه تکمیلی و برخی قواعد تکراری | ادغام و سپس حذف |
| `public/css/filament-fa.css` | فونت CDN، overrideهای عمومی و استایل صفحه تعویض شرکت | فونت محلی، theme مرکزی و اجزای بومی |
| `public/css/mf-funnel.css` | استایل اختصاصی قیف فروش | الگوی مشترک صفحه/برد؛ سپس حذف |
| `public/css/persian.css` | باید مصرف‌کنندگان و هم‌پوشانی آن بررسی شود | قواعد فارسی مرکزی |
| `resources/css/filament/admin/theme.css` | نقطه ورود رسمی Theme | تنها ورودی CSS پنل |

**هشدار:** فایل‌های CSS منتشرشده Filament در `public/css/filament` خروجی vendor/build هستند. حذف یا ویرایش دستی آن‌ها ممنوع؛ باید از source و build اصلاح شوند.

## وضعیت فعلی و محدودیت تأیید

### بسته اجرایی بعدی

- فرم مشتریان به سه بخش اطلاعات اصلی، راه‌های ارتباطی و یادداشت داخلی تقسیم شد؛ نمایش فیلدهای حقوقی همچنان وابسته به نوع مشتری است.
- جدول مشتریان برای موبایل خلاصه‌تر شد: شماره تماس زیر نام، ستون‌های تکمیلی در نمایشگرهای بزرگ‌تر و شناسه به‌صورت اختیاری.
- مجوزهای رکورد، فیلترهای مدل و محدوده company_id تغییر نکردند.


- قیف فروش و فضای کاری تیم با Blade مبتنی بر Tailwind جایگزین استایل‌های قدیمی شده‌اند.
- صفحه تعویض شرکت نیز با الگوی انتخاب فضای کاری، کارت شرکت فعال، نشانگر وضعیت و چیدمان واکنش‌گرا بازطراحی شد؛ منطق Livewire و کنترل عضویت‌ها دست‌نخورده ماند.
- بلوک CSS اختصاصی `sc-*` از `public/css/filament-fa.css` حذف شد؛ قواعد پایه فونت، RTL، فرم، جدول و تقویم جلالی فعلاً باقی مانده‌اند.
- فایل فونت Vazirmatn در مخزن فعلاً موجود نیست؛ فقط فونت‌های Inter خروجی Filament پیدا شدند. بنابراین انتقال فونت فارسی به فایل محلی هنوز انجام نشده و CDN فعلی حذف نشده است.


این تغییر نخستین لایه زیرساخت بصری را اضافه می‌کند و به‌تنهایی به معنی بازطراحی صفحات یا حذف CSSهای قدیمی نیست. CSSهای قدیمی فعلاً حفظ شده‌اند تا صفحه‌ای ناخواسته بدون استایل نشود. مرورگر، Docker و محیط محلی مالک از اینجا قابل اجرا نیست؛ پذیرش بصری پس از build و مشاهده محلی انجام می‌شود.
