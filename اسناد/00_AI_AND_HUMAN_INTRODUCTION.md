## ۱. این پروژه چیست؟

سیستم عملیاتی شرکت (نه CRM خالص):

- چندشرکتی با `company_id`
- بازاریابی (فرصت و قیف)
- کاتالوگ چندماهیتی (اولویت: نوتوپیا)

## ۲. ساختار مخزن (هدف)

```
/
├── اسناد/     ← تمام مستندات و قوانین
└── پروژه/     ← کد Laravel (app, resources, …)
```

**وضعیت فعلی (تا تکمیل بازآرایی):** کد هنوز در ریشه است؛ اسناد سیستم زیر `docs/system/` و این پوشه `اسناد/` هم‌زمان در حال هم‌تراز شدن هستند.  
همیشه **گیت remote** را منبع حقیقت بدانید.

## ۴. الزامات عامل AI

1. قبل از هر تغییر، فایل را از **گیت** بخواند (حدس ممنوع).
2. فقط روی برنچ `develop` کار کند مگر دستور صریح.
3. `company_id` در داده عملیاتی اجباری است.
4. پیام Commit انگلیسی؛ گزارش به انسان فارسی.
5. بعد از هر Push روی remote این دستورها را به کاربر بدهد:

```bash
git fetch origin
git pull origin develop
git log ORIG_HEAD..HEAD --oneline
git diff --name-status ORIG_HEAD..HEAD
```

6. Secret / Token / کلید در مخزن یا چت hardcode نشود.
7. محدوده تغییر = فقط موضوع درخواست‌شده.
8. مسیر دانش: اول `docs/system` و `docs/AGENT_RULES.md`، نه حافظه چت قدیمی.
