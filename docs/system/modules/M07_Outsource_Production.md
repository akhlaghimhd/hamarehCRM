# M07 — Outsource Production (هاب پیمانکار)

| فیلد | مقدار |
|------|--------|
| کد | M07 |
| اولویت | P1 |
| اسکواد | S4 |
| وابستگی | M06 |

## هدف
مدیریت کارگاه‌های بیرونی: شکستن سفارش به بسته‌های کار قابل ارجاع و پیگیری.

## محدوده
- موجودیت **Vendor/Contractor** ساده (نام، تماس، فعال) در company
- **WorkPackage**: order_id، عنوان مرحله (جلد/لت/پلاک/نرم‌افزار/…)، vendor_id، وضعیت، due_at، یادداشت
- وضعیت‌ها: pending، assigned، in_progress، delivered، accepted، rejected
- پیوست فایل (از M00)
- ایجاد دستی از روی Order؛ پیشنهاد خودکار مراحل نوتوپیا (قالب seed)
- لیست کار من / همه بر اساس مجوز

## خارج از محدوده
- زمان‌سنجی ماشین، OEE، موجودی خط تولید داخلی
- قیمت‌گذاری پیچیده پیمانکار (می‌تواند یادداشت باشد)

## قالب مراحل پیشنهادی نوتوپیا (seed)
1. تولید/تأمین جلد
2. لت تبلیغاتی
3. پلاک
4. آماده‌سازی نرم‌افزار/محتوا
5. تجمیع و کنترل نهایی

## کارهای اجرایی
1. مدل Vendor + WorkPackage
2. Resourceها و فیلتر وضعیت/سررسید
3. Action ایجاد بسته از Order
4. تغییر وضعیت با تاریخچه ساده (log یا updated_at + note)
5. اتصال نمایش بسته‌ها در صفحه Order

## DoD
- [ ] از سفارش تأییدشده می‌توان WorkPackage ساخت
- [ ] ارجاع به پیمانکار و تغییر وضعیت ممکن است
- [ ] پیوست روی بسته کار
- [ ] سفارش بدون تولید داخلی MES قابل پیگیری است
