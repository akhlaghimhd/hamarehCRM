## هدف
دید مدیریتی حداقلی و آگاه‌سازی تیم از سررسیدها.

## محدوده
- ویجت داشبورد: تعداد فرصت per stage، کارهای باز من، سفارش‌های باز
- اعلان درون‌برنامه‌ای Filament برای Task/Activity سررسید گذشته یا امروز
- لیست «نیاز به پیگیری»

## خارج از محدوده
- BI، انباره داده، ایمیل مارکتینگ انبوه

## کارهای اجرایی
1. صفحه Dashboard ویجت‌ها
2. Scheduled command یا چک در ورود برای سررسیدها
3. Database notifications
4. لینک مستقیم به رکورد
