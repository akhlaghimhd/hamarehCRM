# M06 — Sales Quote & Order

| فیلد | مقدار |
|------|--------|
| کد | M06 |
| اولویت | P1 |
| اسکواد | S3 |
| وابستگی | M03, M05 |

## هدف
مسیر تجاری از پیشنهاد قیمت تا سفارش قفل‌شده با snapshot پیکربندی.

## محدوده
- **Quote** + خطوط: مشتری، وضعیت، اعتبار، جمع
- هر خط: product_type، ارجاع مدل/کالا، JSON پیکربندی، قیمت واحد/جمع
- اعتبارسنجی از M05 قبل از ذخیره قطعی
- تبدیل Quote تأییدشده → **Order** (کپی snapshot؛ تغییر بعدی کاتالوگ بی‌اثر)
- وضعیت سفارش: draft، confirmed، in_fulfillment، completed، cancelled
- اتصال اختیاری به opportunity_id
- شماره از M00

## کارهای اجرایی
1. مهاجرت quotes, quote_lines, orders, order_lines
2. Resource Quote با فرم پیکربندی نوتوپیا (حداقل انتخاب‌های لازم)
3. Action تبدیل به Order
4. Resource Order فقط‌خواندنی روی snapshot + تغییر وضعیت
5. مجوز جدا برای تأیید سفارش
6. رویداد داخلی ساده برای M07 (Order confirmed)

## خارج از محدوده
- ویرایش آزادانه snapshot بعد از confirmed بدون نسخه
- کانال فروش اینترنتی

## DoD
- [ ] Quote با ترکیب غیرمجاز ذخیره قطعی نمی‌شود
- [ ] Order بعد از تبدیل قیمت/پیکربندی ثابت دارد
- [ ] از فرصت برنده می‌توان به Quote رسید (حداقل لینک)
- [ ] لیست سفارش فیلتر شرکت و مشتری
